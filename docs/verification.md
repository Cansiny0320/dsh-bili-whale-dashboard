## 回归修正

- 多行偏好在每次输入时被立即分割和去空白，导致无法输入换行。先保留编辑文本，再解析列表，回归场景已验证。
- 保存一个设置分组时曾重置其他分组的未保存编辑。改为保留不属于本次保存的编辑，并更新版本基线。
- 读取错误不能当成空数据成功；损坏请求记录显示未确认，旧 `api-ban.json` 暂停纳入状态。
- 系统 pnpm shim 无法执行嵌套 pnpm 命令。项目构建/检查改为直接调用已安装的 Node 工具入口，不改系统配置。
- 按 DSH 当前官方路由合同，prefix 注册路径不能以 `/` 结尾；适配层注册 `/whale-dashboard`，由宿主匹配它及其子路径。模拟宿主也校验此约束。参考：[官方 Web server 文档](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/web-server.md)。
- 原版调度器允许空作息窗口，而保存接口要求至少一个窗口；后台允许读取空配置，在保存前提示补充窗口，并支持将唤醒次数设为 0。
